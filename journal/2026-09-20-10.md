# 2026-09-20 — Names session 1: culture name pools built

Written after the fact by names session 2 (the session hit its usage limit before it could run `/end-session`); derived from the branch history, the handoff it left, and its transcript.

Ran in parallel with the 1b session, on `worktree-flavor-research` off `main` b7ad774. The user brought two demographic tables approximating the Victorian-era world — an imperial-core table (British Isles: English 65, Irish 25, Scottish 8, Welsh 2) and a world table (27 cultures in nine heritage groups, East Asian and South Asian heaviest) — and the rules for using them: every world rolls 1d3 cultures from the world table; every officer's name comes from the core table 60% of the time and the world table 40%. The point is flavour: "planets all have cultural inspirations" and "officers all have a name generated from culture", replacing the syllable generator the user does not like. So each culture needs men's given names, women's given names, family or second names, and place names, all period-correct in that tradition's own terms.

Saved the tables as `design/culture-tables.md` (2a9191c), then built the data: a `Culture` schema in `src/sim/data/names/culture.ts` (given by sex, family, optional feminine family forms, places, a naming `pattern` per sex, `notes` on the record's thin spots), `index.ts` holding `CORE` and `WORLD` as weighted data, and `names.test.ts` enforcing sizes, uniqueness, pattern tokens and index completeness. The user doubled the proposed pool sizes to 80 given names per sex, 80 family, 60 places. Then one commit per heritage group, 17:34 to 21:14: the four British Isles cultures; East Asian; South Asian; European; Middle Eastern; Southeast Asian; African; Indigenous American; Central Asian; Pacific. Cultures without hereditary surnames — Turkish, Persian, Uzbek, Kazakh, Uyghur, Siamese, Javanese — got nisbas, epithets or patronymics and a pattern that says so. One cluster of names that read as copied from a single novel was found and removed from the Igbo file during the build.

Hit the usage limit with the data complete and committed. Wrote `HANDOFF.md` (f6f43b3) listing what remained — draft PR, wiring issue, spot-checks of the five thinnest women's pools, a borrowings sweep, `/end-session` — with the instruction to do all of it through Sonnet subagents given minimal context, since reading the ~300-line culture files into the main session is what exhausted this one. Flagged for the user: Aborigine (thinnest, culturally sensitive), Korean and Siamese women, Han and Javanese women, and the unused Central Asian `family` lists; the user offered to help find alternate sources.

Decisions: the tables and pools are our own data, not derived from any third-party source (recorded in the design doc); pool sizes 80/80/80/60. No `decisions.md` entries were written by this session.

Issues: none opened (the handoff deferred them to names session 2, which filed `#49`–`#51`).
