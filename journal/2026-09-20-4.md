## What was done

The user played the prototype and gave feedback in rounds; each round became a commit on the PR.

- **Inbox compaction** (4bf4f70). Rows open as one line — subject, sender and world, sent / arrived — and expand on click.
- **One report per governor letter** (64d8728). The user: governors should not send a report every time a packet is seen, and sightings and status should not be separate messages. `WorldSnapshot` now carries `ships: ShipSnapshot[]`; `governorReport()` writes one report; `Belief.ships` became a `Sighting {ship, observed, report}` learned from world reports. The opening survey lists no ships (it had been claiming week-0 packet positions as 30-week-old observations). Inbox at week 12 went from ~45 rows to 16.
- **Claims link to their source** (6a5d9e2). "Hulls last seen here" and the dossier's "as of wk N, reported by …" line get a *show report* link that switches to the inbox, opens the report and scrolls to it. Sightings from the desk itself say so. Pure UI: a sighting already carried its report id.
- **Starport dropped from report text** (1284948). It lives in the dossier profile and on the map marker.

Explained on request: solid vs dotted lanes (2-week vs 4-week packet interval — not legible, → #21); the ▲ markers (hulls last seen, per delivered reports — not explained in the UI either, → #21 comment).

## Verdict

**Phase 0 accepted.** The user called the prototype functional and good enough to build Phase 1 on. #16 closed with that verdict.

## Design feedback recorded for Phase 1

- Governors should report on *events*, filtered by loyalty (bad news that would get them in trouble goes unsent) and boldness (may sit on trouble thinking they can handle it; may write only when they need help); good news always goes out. → #20, superseding #17. Noted there: this is the same shape as the Council's reported-truth / rumoured-truth judgement one level up.
- Colour is currently spent on report age; Phase 1 will need it for allegiance. → #21.

## Decisions (rationale in decisions.md)

- One report per letter, hulls in port inside the world snapshot, rather than a message per sighting.
- Sightings carry the id of the report that made them, and the UI links every claim to its source.
