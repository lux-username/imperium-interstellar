# 2026-09-21 — Names session 3, continued: ships named by class

Same session as `journal/2026-09-21-4.md`, after its `/end-session`. The user asked for ship names too — "based on names of British Royal Navy ships, others in the same vein, and what the same themes/org-culture would use in space", at least a hundred per class, separated by class — and for it to go into the prototype.

Wrote `src/sim/data/ships.ts`: six pools, one per hull class that exists (patrol, escort, transport, scout, raider, packet; `merchant` is a role with no hulls yet), 120–150 names each. The themes follow what a blue-water navy actually did with each kind of ship and then carry on in the same voice: patrol craft get the line-of-battle names — qualities, classical figures — and the same grandeur found in the sky (*Meridian*, *Perihelion*, *Antares*); escorts the destroyer tradition of weapons, hunting beasts, weather and brisk adjectives, plus *Meteor*, *Solar Wind*; transports the auxiliaries' home rivers and the "Empire X" names a ministry gives hulls built in a hurry; scouts the survey and despatch tradition of birds, navigation instruments, messengers, winds and exploring verbs; raiders what pirates call their ships — bravado, the old freebooters' names, and bad jokes about money (*Unpaid Tax*, *Second Mortgage*, *Salvage Right*); packets the mail steamers' Latin regions (*Britannia*, *Phoenicia*) and the virtues of a timetable (*Punctual*, *Celerity*). Applied the people-pool rule to ships: a name that is chiefly one famous vessel or a real person went (*Golden Hind*, *Mayflower*, *Royal James*, *Bloody Mary*, *Black Bess*, *Aquitania*); reused traditions like *Dreadnought* and *Discovery* stay. `design/ship-names.md` records the themes and rules.

`shipName(rng, hull, taken)` in `fleet.ts` draws from the class pool, never repeats a name in a game, and numbers the reuse (*Vigilant II*, *III*…) once a pool is spent. The desk's fleet, the Warlord's hulls, pirates and packets all go through it — packets are named hulls now instead of "Packet 37"; the UI already shows the role beside the name. Pools are disjoint across classes so a name also tells the class, and the test says so. The syllable generator, which the user never liked, is deleted from `names.ts`.
